### Added

- Filament-native mobile bottom navigation for Filament 4 and 5.
- Explicit Resource/Page selection and automatic navigation mode.
- Start, center, and end placement for the More item.
- Accessible More sheet backed by Filament's resolved navigation tree.
- Mobile-specific icon contract, safe fallback icon, badges, dark mode, RTL, and safe-area support.
- Automated tests, static analysis, formatting, and multi-version CI.
